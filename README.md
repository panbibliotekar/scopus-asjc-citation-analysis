# Scopus ASJC Citation Analysis

Python workflows for analysing Scopus journal classifications, citation patterns, and disciplinary alignment.

## Methods

The repository contains scripts and notebooks for matching Scopus records, comparing ASJC subject categories, summarising citation patterns, and generating reproducible article samples for independent classification.

## Reproducibility

Analyses use documented input requirements, deterministic procedures where applicable, and audit outputs. See individual scripts and notebooks for execution instructions.

## Data

Scopus exports and licensed reference datasets are not included. Users must provide their own authorised data.
