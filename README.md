# Scopus ASJC Citation Analysis

Python workflows for analysing Scopus journal classifications, citation patterns, and disciplinary alignment.

## Methods

The repository contains scripts and notebooks for matching Scopus records, comparing ASJC subject categories, summarising citation patterns, and generating reproducible article samples for independent classification.

## Reproducibility

Analyses use documented input requirements, deterministic procedures where applicable, and audit outputs. See individual scripts and notebooks for execution instructions.

## Data

The accompanying dataset is available on Zenodo:

Nazarovets, S., & Fraisier-Vannier, O. (2026). *Journal subject classifications and article-level disciplinary assessment: Evidence from Ukrainian Q1 journals* [Dataset]. Zenodo. https://doi.org/10.5281/zenodo.24346476

The dataset includes journal-level CiteScore/ASJC indicators and independent article-level subject classifications for 50 sampled articles. Full Scopus exports and licensed reference datasets are not included; users must provide their own authorised source data.
